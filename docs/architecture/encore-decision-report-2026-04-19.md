# Encore 迁移决策报告（2026-04-19）

当前能力状态：

- `PROD_READY`：迁移决策已正式生效，可作为当前生产主干与季度排期的执行依据。

## 1. 结论

在 2026-04-19 的评审结论中，MistyPass 采用：

- **主干结论：保持现框架（Go + Chi）作为唯一生产主干。**
- **策略结论：暂停 service-by-service 的 Encore 迁移计划，不进入大规模执行。**
- **保留项：仅保留 `Encore.go` 的文档化技术选项，不作为当前季度交付依赖。**

该结论覆盖 `REFORM-CHECKLIST 5.4.2` 的“Encore 框架评估”项。

- 当前主干工程状态（API smoke、nightly soak、安全与观测整改项）

## 3. 决策理由

### 3.1 工程资产复用优先

当前 `Go + Chi` 主干已覆盖认证、网关离线闭环、回放/checkpoint、企业 SSO、钱包发放等关键链路，且具备可执行回归资产。切换框架无法带来同量级业务收益。

### 3.2 风险收益比不达标

Encore 的核心优势在平台治理效率（文档、tracing、服务拓扑），但对 MistyPass 当前最关键的领域能力（离线一致性、幂等补传、状态回放）不是瓶颈替代项。

### 3.3 当前阶段交付目标不匹配

2026 Q2 的优先级仍是安全闭环、稳定性与业务功能补齐。大规模框架迁移会引入额外并行复杂度，拉高回归与上线风险。

## 4. 执行口径（冻结）

- 不新增 Encore 生产服务作为本期里程碑硬依赖。
- 既有 API 与模块继续在 `Go + Chi` 主干演进。
- 如需验证新平台能力，仅允许在隔离 PoC 环境进行，不进入主发布路径。

## 5. 重新开启迁移评审的触发条件

满足任一条件可重新开启评估：

1. 控制面新增服务数量连续两个迭代显著增长，且文档/观测平台税成为主要瓶颈。
2. 现有主干在跨服务可观测性或治理成本上出现可量化持续恶化。
3. 完成外部通道一致性对比后，Encore 对照 PoC 在开发效率/运维复杂度上形成显著正收益。
