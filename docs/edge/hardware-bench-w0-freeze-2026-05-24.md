## Bench Wiring Baseline

| Component | Connection | W0 rule |
| --- | --- | --- |
| SBC power | 5V supply sized for the board and peripherals | Do not power a lock or strike from the SBC. |
| Relay module | GPIO to `IN`, SBC ground to `GND`, relay supply to `VCC` | Confirm GPIO voltage and active level with a multimeter before connecting. |
| Relay load | `COM`/`NO` to lamp or buzzer circuit | No lock body in W0; lamp/buzzer must pass before W1 lock testing. |
| Wiegand reader | `D0`, `D1`, `GND`, reader power | Use level shifting if the reader outputs above 3.3V. |
| RS485 reader | `A`, `B`, `GND` through FT232RNL or equivalent adapter | Add termination only when the reader/adapter path requires it. |
| Door contact | Opto-isolated input to SBC GPIO | Record normally-open/normally-closed state in evidence. |
| REX input | Opto-isolated input to SBC GPIO | Validate idle and active states before API smoke. |
| Tamper input | Opto-isolated input to SBC GPIO | Treat unknown polarity as failed until measured. |

## Safety Gates

1. Measure all reader, 2-channel opto-isolated relay module, and input lines before connecting them to SBC GPIO.
2. Keep the first relay module output connected to a lamp or buzzer, not a lock body.
3. Use an independent 12V supply for any future lock or strike test.
4. Share ground only where the wiring design requires it and voltage has been confirmed.
5. Photograph the full bench, power path, 2-channel opto-isolated relay module wiring, and reader wiring before running smoke tests.
6. Stop the run if any GPIO voltage, input polarity, or 2-channel opto-isolated relay module active level is unknown.

## W1 Entry Criteria

- Frozen IDs above are used without drift, or any change is recorded here before testing.
- Wiring table is filled with actual pins, adapter model, reader model, and measured voltages.
- 2-channel opto-isolated relay module lamp/buzzer pulse succeeds without lock hardware attached.
- API smoke sequence passes against `tenant_demo_jakarta` and `door_jkt_001`.
- No GPIO line, input polarity, reader voltage, or 2-channel opto-isolated relay module active level remains unknown.
- For Roaming-Test, the 2-channel opto-isolated relay module active level is known before the 12V maglock is connected.
